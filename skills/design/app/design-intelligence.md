## 🖋️ Weight & Emphasis Protocol
1.  **Maximum Impact (900/Black)**:
    *   **Usage**: Display Hero values, H1/H2 Headings, Industrial Labels, and Action Buttons.
    *   **Rationale**: High-density UI requires extremely strong weights to maintain hierarchy against dense information.
2.  **Functional Bold (700/Bold)**:
    *   **Usage**: Subheadings, Card Titles, and Primary UI Text.
3.  **Medium Clarity (500/Medium)**:
    *   **Usage**: Secondary descriptions and Body text (Inter).
4.  **Letter Spacing (Tracking)**:
    *   Labels: `0.25em` (Extreme tracking) for ultra-modern "Technical" look.
    *   Headings: `-0.02em` (Tighter) for a "Premium Print" feel.

## 🤖 Claude Design Deep-Dive (Methodology)
1.  **Full-Bleed Viewport Anatomy**:
    *   Abandoning the "phone frame" shell in favor of `100vw/100vh` full-bleed containers.
    *   Using fixed `env(safe-area-inset-bottom)` aware footers for native-feel padding.
2.  **Gradient Stacking (The "Glow" Method)**:
    *   Layering multiple `radial-gradient` stops over a `linear-gradient` base to create a sense of light sources within the UI.
    *   Applying `box-shadow: 0 0 0 4px ...` to create a "secondary ring" effect around primary glow elements (the orb).
3.  **Interactive Iconography**:
    *   A "hide-when-active" strategy for the bottom nav: The floating glow orb physically takes over the icon position of the active tab, hiding the underlying static icon for a "swapping" feel.
4.  **Density & Contrast**:
    *   Using extremely high weights (850-900) for display numbers but keeping body text light (Inter 500) to ensure readability without losing industrial "toughness."
